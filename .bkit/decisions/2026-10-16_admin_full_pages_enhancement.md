# 2026-10-16 관리자 잔여 페이지(상담·리드·게시판·칼럼) 전면 고도화

## 1. 개요
대시보드, 방문 통계, 관리자 계정 관리 외의 관리자 페이지(전화/방문 상담, 빠른 상담 리드, 1:1 게시판 상담, 법률 칼럼 및 성공사례 관리)를 전수 검토하고 실무 편의성과 고객 응대 속도를 대폭 개선하는 검색·필터·엑셀(CSV) 내보내기·상세 조회 모달 및 데이터 삭제 시스템을 구축하였습니다.

---

## 2. 주요 개선 사항

### 2.1 전화/방문 상담 관리 (`src/app/admin/consultations/page.tsx` & `/api/admin/consultations/list`)
- **실시간 다중 검색**: 이름, 연락처, 지역, 상담내용 키워드 검색 지원.
- **상태 필터링 탭**: 대기중, 연락완료, 진행중, 완료, 취소 등 상태별 모아보기 제공.
- **상세 보기 모달 (`selectedItem`)**:
  - 고객이 접수한 상세 상담 내용, 희망 방문일시, 거주 지역을 팝업으로 즉각 열람.
  - 모달 내에서 처리 상태를 원클릭으로 즉시 변경.
- **CSV 다운로드**: 접수된 전화/방문 상담 명단을 엑셀용 CSV 파일로 1클릭 내보내기.

### 2.2 빠른 상담 리드 관리 (`src/app/admin/leads/page.tsx` & `/api/admin/leads`)
- **실시간 검색 지원**: 이름, 연락처, 지역, 희망제도, 상담내용 검색.
- **상태별 필터**: PENDING(대기중) 고객만을 선별하여 미처리 고객 누락 방지.
- **CSV 다운로드**: 리드 데이터를 즉시 엑셀 파일로 추출 가능.
- **수동 새로고침 및 대기 건수 배지** 탑재.

### 2.3 1:1 게시판 상담 관리 (`src/app/admin/board/page.tsx` & `/api/board-qna`)
- **실시간 검색**: 제목, 작성자명, 문의 본문 검색.
- **상태 필터링**: 전체 / ⏳ 미답변 / ✅ 답변완료 탭 분리.
- **관리자 전용 삭제 API 신설 (`DELETE /api/admin/board/[id]`)**: 스팸 및 테스트 글을 관리자가 안전하게 영구 삭제할 수 있는 기능 추가.
- **답변 모달 UI 개선**: 답변 저장 시 자동으로 '답변완료' 상태로 전환.

### 2.4 법률 칼럼 & 성공사례 관리 (`src/app/admin/columns/page.tsx`)
- **실시간 칼럼 검색**: 제목, 태그(#키워드), 요약문 검색 지원.
- **공개/비공개 필터 탭**: 발행 상태별 정렬 기능.
- **의뢰인 화면 실시간 바로가기(새 창 열기 링크)**:
  - About 개인회생 (`/rehab/posts/[id]`), About 개인파산 (`/bankruptcy/posts/[id]`), 성공사례 (`/s_story/posts/[id]`)로 실제 사용자 화면에서 어떻게 노출되는지 1클릭으로 확인 가능.
