# 2026-10-16 관리자 페이지 상담/리드/게시판 테스트 신청 데이터 삭제 기능 구현

## 1. 개요
- **배경**:
  - 관리자가 시스템 테스트 및 기능 점검을 위해 입력했던 테스트 신청 건들을 화면에서 직접 삭제할 수 있는 기능이 빠른 상담(리드) 및 전화/방문 상담 페이지에 부재했음.
- **목표**:
  - 관리자 페이지의 모든 상담 영역(빠른 상담 리드, 전화/방문 상담 예약, 1:1 게시판 문의)에서 테스트 데이터를 개별 및 모달에서 즉각 안전하게 삭제할 수 있도록 구현.

---

## 2. 주요 구현 내용

### 2.1 백엔드 DELETE 엔드포인트 추가
1. **빠른 상담 리드 (`DELETE /api/admin/leads/[id]`)**:
   - 관리자 세션 검증 후 해당 Lead 레코드 영구 삭제.
2. **전화/방문 상담 예약 (`DELETE /api/admin/consultations/[id]`)**:
   - 관리자 세션 검증 후 해당 Consultation 레코드 영구 삭제.
3. **1:1 게시판 문의 (`DELETE /api/admin/board/[id]`)**:
   - 기 구현된 삭제 엔드포인트 활용.

### 2.2 프론트엔드 UI 삭제 기능 연동
1. **빠른 상담 (리드) 관리 (`/admin/leads`)**:
   - 목록 테이블 각 행에 `관리` 열 및 **휴지통 [삭제] 버튼** 탑재.
   - 고객 상세 보기 팝업 모달 하단 푸터에 **[삭제] 버튼** 연동.
   - 클릭 시 확인 컨펌 후 삭제 및 실시간 목록 갱신.
2. **전화/방문 상담 예약 관리 (`/admin/consultations`)**:
   - 목록 테이블 각 행에 `관리` 열 및 **휴지통 [삭제] 버튼** 탑재.
   - 상담 상세 보기 팝업 모달 하단 푸터에 **[삭제] 버튼** 연동.
   - 클릭 시 확인 컨펌 후 삭제 및 실시간 목록 갱신.
3. **1:1 게시판 상담 관리 (`/admin/board`)**:
   - 목록 테이블 행의 **휴지통 [삭제] 버튼** 및 상세 모달의 **[삭제] 버튼** 기 완비.
