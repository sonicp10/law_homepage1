# 2026-10-16 관리자 비밀번호 변경 기능 신설 및 계정 관리 개선

## 1. 개요
관리자 페이지에서 본인의 비밀번호를 직접 변경할 수 있는 기능의 부재 및 관리자 계정 목록에서 특정 관리자의 비밀번호를 재설정(초기화)할 수 있는 UI/UX 결손 문제를 해결하기 위해, 보안 검증이 완비된 비밀번호 변경 전용 API와 모달 UI를 전면 구현하였습니다.

---

## 2. 구현 세부 사항

### 2.1 본인 비밀번호 변경 API 신설 (`POST /api/admin/auth/change-password`)
- **보안 세션 검증**: 유효한 관리자 세션 쿠키 토큰(`admin_session_v1`)이 있는 경우에만 접근 허용.
- **현재 비밀번호 검증**: 기존 비밀번호를 bcrypt로 검증하여 일치하지 않을 경우 즉시 요청 차단.
- **새 비밀번호 정합성 검사**:
  - 최소 6자리 이상 길이 체크.
  - 새 비밀번호 확인 일치 여부 체크.
  - 현재 비밀번호와 동일한 새 비밀번호 사용 방지.
- **비밀번호 단방향 암호화**: `bcrypt.hash(newPassword, 10)`를 거쳐 DB `User` 테이블에 안전하게 반영.

### 2.2 관리자 사이드바 비밀번호 변경 UI (`src/app/admin/layout.tsx`)
- 관리자 사이드바 하단 프로필 영역에 접속 중인 관리자 계정(이메일, 이름, 역할)과 함께 **[비밀번호 변경]** 버튼 배치.
- 클릭 시 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인을 입력받는 직관적인 모달(`ChangePasswordModal`) 제공.
- 변경 성공 시 알림 및 폼 초기화, 오류 발생 시 명확한 에러 메시지 피드백 제공.

### 2.3 관리자 계정 관리 페이지 비번 재설정 지원 (`src/app/admin/accounts/page.tsx`)
- 관리자 계정 목록 테이블의 각 계정별 관리 열에 **[비번 변경]** 버튼 추가.
- 클릭 시 대상 관리자의 이메일과 이름을 확인하며 새 비밀번호를 설정할 수 있는 `ResetPasswordModal` 연동.
- `PATCH /api/admin/accounts/[id]` API를 통해 마스터 관리자가 다른 관리자의 비밀번호를 안전하게 재설정 가능.
